The honest status: this is a **complete concept-to-preliminary design package**. Before cutting metal,
each envelope part goes through a detailing pass that adds holes, threads, fillets and
datum features. The four detailed parts above show the standard to reach. Then FEA (docs/11 §3).

## 7. Electronics manufacturing

* **Drive carrier** (26), **PDU**, **disconnect board**, **safety MCU board**, **hand controller** (2), **foot board** (2):
  4–6 layer FR-4, 2 oz copper on power layers, ENIG finish, JLCPCB/PCBWay assembly.
  Every board gets a test pad set and a scripted bring-up test (docs/10 P2).
* **Harness:** build on a printed nail-board from the CAD routing; label every wire; 100 % continuity
  and insulation-resistance test (500 V, > 100 MΩ) before installation.

## 8. Battery pack manufacture

See docs/10 phase P6 (step-by-step) and docs/05 §3. Build in a cleared area with a sand
bucket and a Class D (lithium) or large CO₂/water mist extinguisher, never alone.

## 9. Inspection plan

| Part class | Inspection |
|---|---|
| Bearing seats, gear bores | bore gauge / CMM, 100 % |
| Gears | gear report from the supplier (profile, lead, runout) + incoming double-flank check |
| Flatness-critical plates | surface plate + dial indicator |
| Ti parts | dye-penetrant crack inspection after machining |
| Bonded tube joints | proof load 1.5× structural-case axial + torsion on a test coupon from each batch |
| Shells | fit check on the assembly before painting |
| Cells | 100 % mass, OCV and 1 kHz IR; reject outliers (R3) |
