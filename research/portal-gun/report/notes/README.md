# Source notes

These seven files are the working notes from the literature phase of the study, kept unedited as the
evidence base for the report. Each was written on 2026-10-19 by a research agent working from primary
sources (arXiv and publisher PDFs, scanned papers, standards documents, retailer pages, the Rick and Morty
wiki's API), and each records, per source, whether the full text, only the abstract, or only the
bibliographic record was accessed.

| File | Scope |
|---|---|
| `01-gr-geometry.md` | Einstein–Rosen; Morris–Thorne; Ellis–Bronnikov; Visser's thin-shell and flat-face wormholes; stability; lensing |
| `02-energy-conditions-qft.md` | Energy conditions; quantum inequalities; Casimir effect and its measurements; holographic and 4-D traversable wormholes |
| `03-topology-causality-qg.md` | Topology change; time machines; chronology protection; topological censorship; mouth dynamics; ER=EPR; the 2022 quantum-processor experiment |
| `04-experiments-analogues.md` | Metamaterial and analogue wormholes; clock tests of gravitational time dilation; teleportation; illusions; astronomical searches |
| `05-rick-and-morty-canon.md` | What the show establishes about the portal gun, with episode evidence and confidence |
| `06-prop-hardware.md` | Verified parts, prices (2026-10-19) and safety sources for the prop |
| `07-portal-rendering.md` | Oblique-projection rendering, three.js r186 API facts, Valve and other portal implementations, physics references |

How to read them:

- Quotations are verbatim and kept short; everything else is the note-taker's paraphrase. Numbers the
  note-takers computed themselves are labelled as such ("my check", "[DERIVED]", "[my calculation]").
- Where the notes disagree with each other about access (one agent read a paper in full that another saw
  only as an abstract), the reference list uses the better access.
- The notes mention scratch scripts and downloads in a session workspace (`scratchpad/...`); those were not
  kept. The one check that mattered for the code, the oblique-projection numerics in `07` section 8, is
  covered by the simulator's unit test 14.
- Each file ends with a "discrepancies and open questions" section; the report's corrections to commonly
  repeated claims (for example, that the Casimir estimate is in the Morris–Thorne–Yurtsever letter, not the
  1988 AJP paper) come from there.
