            Shield

            The shield cuts every limit to a quarter for everyone outside the staff addresses. The sentinel raises it by itself when many addresses misbehave at once, and lowers it when they stop.

              Setup

              Three steps connect this server to your school: a name people can type, an email account to send alerts through, and who should be told. Do them in any order. Each one is saved by itself.

              Step 1. Your school's domain

              Usually a short word in front of the school's own domain, such as play.yourschool.example.

              What to ask for

              The name is pointed at this server by a DNS record. That is changed wherever the school's domain is managed (the school's IT provider, the department, or the company the domain was bought from), not on this server. Send them this:

                A new record can take from a few minutes to a day to reach everyone.

                The certificate that makes the padlock in the browser

                This server is using a certificate the school supplied. Choosing one of these replaces it.

                Step 2. Email

                Alerts by email are sent through an ordinary mail account: the school's own, or a free one kept for this. Mail is only ever sent encrypted.

                  Usually the same as the account.

                  Step 3. Who is told

                  There are three lists, so each person hears only what they need. An entry is an email address, a phone push written as ntfy:topic, or a Telegram chat written as telegram:chat number.

                  A phone push topic already on a list shows only its first letters, because anyone who knows the whole name can read its alerts. Leave it as it is and it keeps working.

                    You have changes that are not saved yet.

                    Pushes to a phone

                    Install the free ntfy app on the phone. Make a topic here, subscribe to that name in the app, then add it to a list. No account is needed.

                    Using Telegram?

                    Make a bot with Telegram's BotFather, give the bot's token to the server here, then send the bot one message so it may write to you.

                    Health

                    Self-check

                    The server checks that each of its protections is still in place. Anything that failed comes first.

                      Services

                        A restart takes under a minute. Use it when the site has stopped answering.

                        Backups

                        The server makes an encrypted backup every night. Make one now before a change you are unsure about.

                        Support access

                        Support access lets one helper connect from one address for a few hours and run a short list of safe commands. It is opened at the server's own screen and closes by itself.

                        The analyst

                        The analyst is a small AI model on this server that adds a second opinion to security alerts. It only advises: the sentinel bans and unbans by its own rules before the analyst is asked. It is switched on and off at the server's own screen.
