# Sets 2: sound in questions, media that lasts, the set's feel, editor tools, games that adapt

Branch `wip/sets2`. Migration `0020_setmedia.sql` (a `upload_files` table; `audio/wav` allowed in `uploads.mime`). No new dependencies.

## Notes

- Hint cost: no mode charges for opening a hint; it is shown on the player's own screen and the server does not know it was opened.
- Bots: questions now may carry `sound` and `hint`. Bots answer from the authored answer, so neither changes how they play.
- The set's right, wrong and win sounds replace the game's `correct`, `wrong`, `win` and `fanfare` effects only while a room from that set is open.
