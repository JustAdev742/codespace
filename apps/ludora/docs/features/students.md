# Students: what a player gets outside a live game

Branch `wip/students`. Migration `0013_students` (tables `mistakes`, `practice_runs`, `player_extras`,
`notifications`, `quest_swaps`, at the end of `server/src/db/schema.ts`). No new dependencies. Nothing here
mints Sparks or items: practice games pay the ordinary game rewards (solo multiplier, daily cap), and the
level track shows the existing level rewards.

Tests named below: `server/test/students.test.ts` (21 tests), `web/src/features/quests/groups.test.ts` (2),
`e2e/students.spec.ts` (2 browser tests, each page checked with axe WCAG 2.2 A/AA at 390x844 and 1366x768 in the
day and night themes, no sideways scroll, no console errors), passing in Ludora's look and with `E2E_SCHOOL_THEME=hills-grammar`.

## Changed from the brief, and not done

- **Level track rewards are not claimable.** Level rewards were already paid automatically, once, inside the XP
  operation. A claim step would add a chore and change the reward rules; the track shows them as received.
- **Not done, because the files belong to the live-game agent** (`features/room/**`): how-to-play cards before a
  game (17, the mode page already has the rules), solo against bots at a chosen skill (22, bots live in the room),
  choosing reactions for the bar (26, the bar is fixed in the room code), and an invite button inside the room.
- **Challenge a friend (23)** was not built.
- The recap card and the teacher checklist were checked by server tests and `tsc`, not seen filled in a browser.
