# SIL Ready — NDIS SIL registration sprint business

Objective: A$32,500 in legitimate revenue. Strategy, evidence and live numbers are in `docs/`.

| Where | What |
|---|---|
| `docs/DASHBOARD.md` | Live revenue/funnel dashboard (real numbers only), regenerated by `tools/funnel.py` |
| `docs/DECISION.md` | What we sell, to whom, why, at what price, how we reach them, pivot triggers |
| `docs/OWNER-ACTIONS.md` | Every action that needs the owner: Stripe, Pages, domain, sending identity, approvals |
| `docs/DELIVERY-RUNBOOK.md` · `docs/INTERVIEW-GUIDE.md` | How a sprint is delivered in 5 business days |
| `docs/research/` | Market research, scoring, deep dives, sources, customer feedback log |
| `site/` | Static sales site + intake form (GitHub Pages); owner fills `site/config.js` |
| `content/policies/*.md` | Tailorable policy/procedure/register templates (Markdown + Jinja2), spec in `content/TEMPLATE-SPEC.md` |
| `engine/render.py` | intake JSON → tailored DOCX/HTML set + evidence index; `engine/brief.py` → staff briefing pack |
| `outreach/` | Email sequences, partner pitches, phone scripts, posts, prospecting playbook |
| `tools/funnel.py` · `tools/prospects.py` | Funnel/revenue tracker; prospect list normaliser and verification worklist |

## Run
```
pip install python-docx jinja2 pyyaml
python3 engine/render.py --intake content/intake.example.json --out build/example --html
python3 engine/brief.py  --intake content/intake.example.json --out build/example/STAFF-BRIEFING-PACK.docx
python3 tools/funnel.py render
```

## Data handling
This repository is public. `data/funnel.json`, `data/clients/`, prospect lists and rendered client documents are git-ignored and must never be committed. The dashboard shows customer codes, not names.
